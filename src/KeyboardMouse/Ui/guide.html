Which actions have a key

Grid keys

One key per cell of the 3 x 3 grid, top row first.Every cell prints four of these ten keys: column band, column, row band, row.

In grid mode: a cell key moves the pointer into that cell and narrows the grid to it; after the last level the grid closes with the pointer there. Backspace goes up a level, Tab or the Grid key stops here, Space or Enter click, the Next monitor key (N) switches monitor, Esc cancels.

In grid mode: a full code only moves the pointer and closes the grid, so the click is your own Space; Space or Enter pressed inside the grid click straight away, Tab moves and closes, N switches monitor, Backspace goes back, Ctrl + the Grid key closes, Esc cancels.

Quick reference

Power moves

Moving across a big screen with I J K L is fine — but these are much faster.

G

Grid jump

One grid of small cells covers the screen and every cell is printed with the four letters that reach it, from the moment it opens. The lattice follows the monitor: a bigger screen is cut into more cells, never into wider ones. Read the cell you want and type its four letters: the pointer jumps there and the grid closes itself. It never clicks for you — the click is your own Space. The rest of the grid dims as you type.

  • A S D F G H J K L ; — the ten letters every code is made of
  • A code reads column band, column, row band, row — SFAK is column 13, row 7
  • Tab moves there and closes without clicking · N next monitor · Esc cancel · Backspace back · then Space clicks where the pointer landed
H

Hints

Every button and link gets a short label. Type the label and it is clicked — no aiming at all.

  • Labels use only home-row letters: A S D F J K L ;
  • Shift + label = hover · F + label = right click
D

Scroll layer

D+K

Hold D and the movement keys scroll instead of moving. Smooth, and it speeds up as you hold.

  • D + I/K up/down · D + J/L sideways
  • D + U/O page up/down · add Ctrl to zoom
B

Auto clicker

0

Press B and it clicks for you, again and again, wherever the pointer is. Keep moving while it runs. Press B again to stop.

  • The indicator turns yellow while it runs
  • Speed and button: Settings → Auto clicker

More moves

V

Drag lock

Holds the left button down so you can move freely. Press V or Space to drop.

T

Click & type

Clicks a text box and leaves mouse mode in one key, so you can start typing.

SA

Speed

Hold S for pixel-precise moves, hold A for turbo across the screen.

XCN

Jumps

Center of the screen, center of the window, or the next monitor.

M'

Marks

M then a letter saves the spot; ' then the letter jumps back. Saved across restarts.

CtrlAlt⌫

Panic

If a button ever feels stuck: releases everything and leaves mouse mode.

KeyboardMouse

Your privacy

  • Never records or saves what you type.
  • Stays offline unless you turn on update checks (GitHub only).
  • All source code is public on GitHub.

Good to know

  • Admin windows (e.g. Task Manager) only respond if KeyboardMouse runs as administrator.
  • Some games ignore simulated input.
  • Works together with a TrackPoint, touchpad or mouse.

Shutdown or restart

Shutdown stops the app completely and your keyboard goes back to normal right away. Restart closes it and starts it again.

Settings saved. Restart the app so every change is fully applied.
